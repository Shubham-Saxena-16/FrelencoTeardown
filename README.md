# Frelenco Website Teardown

A frontend recreation and teardown of the Frelenco website, created to understand and demonstrate website structure, user experience, layout, and frontend implementation.

## Overview

This project recreates the Frelenco website interface using HTML, CSS, and JavaScript.

The purpose of this project is to:

- Analyze the existing website structure and user experience
- Recreate the key visual and interaction patterns
- Practice frontend implementation
- Understand how different website sections are structured
- Explore opportunities for UX and product improvements
